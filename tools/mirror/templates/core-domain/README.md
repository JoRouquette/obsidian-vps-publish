# @core-domain — Publish to VPS

Domain layer of the [Publish to VPS](https://github.com/JoRouquette/obsidian-vps-publish) stack: entities, value objects, and interfaces shared by the Obsidian plugin and the self-hosted API. Framework-agnostic, no runtime dependency.

> **Read-only mirror.** This repository is regenerated from the monorepo on every stable release — do not open pull requests here.
